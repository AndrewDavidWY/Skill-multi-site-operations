# 多站点运营数据整合与每日更新

先证明“取的是哪个站点、哪段时间、什么口径”，再生成比较和建议。优先使用现有只读连接；手工导出是有效起点，不为了做日报自动新建凭据或扩大权限。

## 建立站点数据契约

核实站点 URL、GA4 property ID、web stream/measurement ID、主机名与跨域关系、属性时区、指标、日期范围、过滤器和负责人。property ID 与 `G-...` measurement ID 不是同一个值，不可互换。

阅读 [数据契约](references/data-contract.md)，按 [合成配置](assets/sites.example.json) 记录每个站点的确切范围。多个站点共享一个 property 时，明确如何按主机名或其他已验证规则分开；不要对每个站点重复使用整份 property 总量。

对齐指标 API 名称和业务含义，尤其 activeUsers 与 totalUsers、浏览量与事件数、关键事件与实际有效线索。没有共同计量口径时并列显示，不强行排名。用户数跨天/跨站不可简单求和去重，比例应基于同口径分子分母计算，货币要先统一汇率规则。

## 访问最小化与首轮验真

为每个 property 确认已授权身份与可读范围。读取日报通常只需相应 property 的只读能力，不要求账号管理员权限。Google Analytics 角色和 OAuth scope 是不同层的限制，参考 [访问与自动化](references/access-and-automation.md)。创建新服务账号、OAuth 授权或长期访问、添加成员、处理凭据时先取得适用批准；不把凭据写入仓库、配置样例或日报。

先完成一次手工验证：在 GA4 UI 与导出/API 中使用同一 property、日期、时区、指标和过滤器，记录对账结果及差异解释。核实采集时再查看真实站点、Tag Assistant/DebugView 或 Realtime；HTTP 成功、埋点代码存在与正式报告有完整数据是三件事。尊重现有 consent 逻辑，不绕过隐私选择。

## 采集与质量检查

按站点独立采集，保留请求口径、取数时间、数据日期、方法和结果。明确分页完成情况；保留 API 返回的抽样、阈值、`(other)`、截断、指标受限、空结果及属性时区等元数据。UI 或手工导出没有对应质量元数据时写“未知”，不要补成 false。

失败站点不拖累其他站点，但必须保留缺口。`0` 只表示成功查询得到的真实零值；无权限、未连接、未采集、超时、空报告或缺行都不能自动填零。查询近日期时预留处理延迟，后续修订保留版本。官方说明报告处理可能需要 24–48 小时，具体刷新取决于属性与报告；这不是自动保证数据最终完整。

使用 `python3 scripts/check_daily_snapshot.py assets/sites.example.json assets/snapshots.example.json --report-date 2026-01-12 --as-of 2026-01-15T12:00:00Z` 对合成快照做离线核对。脚本不登录 Google、不联网取数、不调度任务；它检查映射、口径、重复行、时间、质量状态和缺失值，并保留声明的演示／真实快照来源模式；不会验证该声明真实。

## 每日报告与自动化验收

按 [日报模板](assets/daily-update.md) 输出：覆盖站点及缺口、数据日期和取数时间、每站指标与可比变化、异常证据、建议动作及负责人。先报影响决策的异常，不用空泛评价填充日报。比较期应时长、星期结构、过滤器、时区和处理成熟度相近；基期为零不计算普通百分比增长。

一次采集成功不等于每日更新已运行。只有用户要求持续更新时，才配置已批准的调度与发送目的地；部署后手工执行一次，再核对真实的定时触发、产物和送达结果。记录失败告警、重试边界、重跑幂等性和最近成功时间。尚未验证定时运行时明确说“手工采集已通过，定时更新待验证”。

每日保留“报告生成时间”和“数据实际截至日期”。缓存结果可以展示为最近已知值，必须保留原取数时间和 stale 标记，不以当天生成报告掩盖数据没有更新。处理窗口内取得的快照不会因等待自动成熟，窗口结束后需要重新取数才能解除 provisional。权限失败或配额错误不无限重试，不静默更换 property 或指标。

## 完成标准

站点映射、指标口径、读取权限、至少一轮人工/API 对账和数据时效均有证据；日报正确显示零值、缺失、部分覆盖与过期。若包含自动化，另有真实调度与交付证据。公开 Skill 仓库仅包含通用方法与合成数据。项目看板可按用户明确授权公开真实聚合数据，但需另建经审查的字段白名单，保留来源模式、数据日、原取数时间及质量状态；不直接公开此检查器的完整输出、原始查询、身份信息或凭据。
